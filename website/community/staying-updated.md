### 新闻

Twitter 是团队用来发布更新、新闻和征集参与的主要沟通渠道之一：关注 [React Native 账号](https://twitter.com/reactnative) 以保持最新动态 - [ReactJS 账号](https://twitter.com/reactjs) 同时涵盖 React 和 React Native。

对于长篇新闻和公告，请关注 [博客](/blog)，了解 React Native 世界正在发生什么。

### 讨论与协作

React Native 是一个动态框架，始终有改进空间。作为一个开源框架，大规模协调和讨论应继续保持公开可访问。以下是一些专门的讨论组，你可以参与其中：

重要讨论应始终保持公开；根据主题不同，你可以在以下地点找到它们：

- [框架讨论、提案和 RFC](https://github.com/react-native-community/discussions-and-proposals/discussions)
- [发布状态和问题](https://github.com/reactwg/react-native-releases/discussions)
- [新架构采用与反馈](https://github.com/reactwg/react-native-new-architecture/discussions)
- [开发者体验改进](https://github.com/react-native-community/developer-experience-wg)

### 包与集成

在 [React Native Directory](https://reactnative.directory/) 中，你可以看到许多与 React Native 兼容的库。这是一个由社区推动的项目，旨在帮助开发者浏览和评估包、插件、状态管理库等。
