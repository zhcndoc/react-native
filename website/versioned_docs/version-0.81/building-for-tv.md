TV 设备支持的实现旨在使现有的 React Native 应用程序能够在 Apple TV 和 Android TV 上运行，而应用程序的 JavaScript 代码只需很少或无需更改。

:::warning[已弃用]
TV 支持已移至 [React Native for TV](https://github.com/react-native-tvos/react-native-tvos#readme) 仓库。有关 Apple TV 或 Android TV 项目的信息，请参阅那里的 **README**。
:::
