## 可尝试的平台

[Expo](https://docs.expo.dev/) 是一个面向 React Native 的工具和服务框架，专注于帮助你构建、发布和迭代应用，使用在 Web 开发中流行的预览部署工作流，并自动化你的开发工作流。Expo 还可以让你完全无需接触 Xcode 或 Android Studio 就构建 React Native 应用；如果你想使用这些工具，它也不会妨碍你

[Ignite](https://github.com/infinitered/ignite) 是一个包含多个 React Native 样板的入门套件 CLI。最新版本 Ignite Maverick 使用 MobX-State-Tree 进行状态管理、使用 React Navigation，以及其他常用库。它为屏幕、模型等提供生成器，并且开箱即支持 Expo。Ignite 还附带一个针对自定义设计进行优化的组件库，支持主题和测试。如果你正在寻找预配置的技术栈，Ignite 可能非常适合你

## 查找、创建和分享你自己的 Native Components 和 TurboModules

React Native 拥有一个由数千名像你一样的开发者组成的社区，他们正在制作内容、工具、教程，以及 Native Components！

在 Core Components 中找不到你需要的内容？访问 [React Native Directory](https://reactnative.directory)，查找社区正在创建的内容

:::caution
本文档引用了一组旧版 API，需要更新以反映 New Architecture
:::
有兴趣创建自己的 Native Component 或 Module 吗？为自己的使用场景创建模块，并通过 NPM 和 GitHub 与他人分享，有助于壮大 React Native 生态系统和社区！阅读创建自己的 Native Modules（[Android](legacy/native-modules-android.md)、[iOS](legacy/native-modules-ios.md)）和 Native Components（[Android](legacy/native-components-android.md)、[iOS](legacy/native-components-ios.md)）的指南。
