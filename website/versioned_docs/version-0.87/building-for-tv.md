TV 设备支持已实现，旨在让现有的 React Native 应用能够在 Apple TV 和 Android TV 上运行，而应用的 JavaScript 代码几乎无需或完全无需修改

:::warning[已弃用]
TV 支持已移至 [React Native for TV](https://github.com/react-native-tvos/react-native-tvos#readme) 仓库。有关 Apple TV 或 Android TV 项目的信息，请参阅其中的 **README**
:::
