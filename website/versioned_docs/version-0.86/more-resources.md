## 可尝试的平台

[Expo](https://docs.expo.dev/) 是一套面向 React Native 的工具和服务框架，重点帮助你构建、发布并迭代应用，使用在 Web 开发中很流行的预览部署工作流，并自动化你的开发工作流。Expo 还使你可以在完全不接触 Xcode 或 Android Studio 的情况下构建 React Native 应用，而且如果你想使用这些工具，它也不会妨碍你。

[Ignite](https://github.com/infinitered/ignite) 是一个带有多个 React Native 脚手架模板的启动套件 CLI。最新版本 Ignite Maverick 使用 MobX-State-Tree 进行状态管理、React Navigation 以及其他常用库。它提供用于屏幕、模型等的生成器，并且开箱即支持 Expo。Ignite 还附带一个组件库，针对自定义设计、主题支持和测试进行了优化。如果你正在寻找预配置的技术栈，Ignite 可能非常适合你。

## 查找、创建并分享你自己的原生组件和 TurboModules

React Native 拥有一个由成千上万像你一样的开发者组成的社区，他们在创建内容、工具、教程——以及原生组件！

在 Core Components 中找不到你要的内容？访问 [React Native Directory](https://reactnative.directory) 来查找社区一直在创建的内容。

:::caution
此文档引用了一组旧版 API，需要更新以反映新架构
:::
有兴趣创建你自己的原生组件或模块吗？为你自己的用例创建模块，并在 NPM 和 GitHub 上与他人分享，有助于壮大 React Native 生态系统和社区！阅读关于创建你自己的原生模块（[Android](legacy/native-modules-android.md)、[iOS](legacy/native-modules-ios.md)）和原生组件（[Android](legacy/native-components-android.md)、[iOS](legacy/native-components-ios.md)）的指南。
