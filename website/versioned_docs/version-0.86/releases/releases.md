React Native 的新版本每 **两个月** 发布一次，通常每年会产生 6 个新的次版本。

<ReleasesTable />

表格中展示的不同支持级别定义如下：

- **未来**
  - 在切出新版本分支后，尽快创建新的候选发布版本（Release Candidate）以便社区测试即将到来的版本，这一点非常重要。新的 RC 发布会以较高频率进行，只要条件允许就会尽快发布。
- **活跃**
  - 处于活跃支持中的稳定版本会收到频繁更新。最新稳定版优先级最高，并且在其稳定周期开始时（也就是刚发布 .0 之后），会尽快进行多个补丁发布，以稳定该版本并确保社区获得良好的升级体验。
- **周期结束**
  - 处于此支持范围内的版本将收到较少的补丁，除非需要处理一些重要的回归问题。一旦下一个版本成为新的最新稳定版，在 EoC 版本转入不受支持状态之前，系统会基于最新收到的挑选请求（pick requests）生成并发布最后一个补丁。
- **不受支持**
  - 当一个版本处于不受支持阶段时，不会再有新的发布。只有非常重要的回归问题可能会打破这一规则；建议使用不受支持版本的代码库尽快升级。

## 对稳定性的承诺

为了支持用户升级 React Native 版本，我们承诺维护**最近 3 个次版本系列**（例如，当 0.78 是最新发布时，维护 0.78.x、0.77.x 和 0.76.x）。

对于这些版本，我们会定期发布更新和错误修复。

你可以在 [react-native-releases 工作组](https://github.com/reactwg/react-native-releases/blob/main/docs/support.md) 了解更多关于我们的支持策略。

关于我们的版本号规则，以及我们认定的破坏性变更，更多信息可在 [版本号策略](./releases/versioning-policy) 页面查看。
