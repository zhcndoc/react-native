电视设备支持的实现目的是让现有的 React Native 应用可以运行在 Apple TV 和 Android TV 上，且在应用的 JavaScript 代码中几乎无需或无需做任何修改。

:::warning[已弃用]
电视支持已迁移到 [React Native for TV](https://github.com/react-native-tvos/react-native-tvos#readme) 仓库。有关 Apple TV 或 Android TV 项目的信息，请参阅那里的 **README**。
:::
