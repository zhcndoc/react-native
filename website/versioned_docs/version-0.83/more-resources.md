## 可以尝试的平台

[Expo](https://docs.expo.dev/) 是一个针对 React Native 的工具与服务框架，专注于帮助您构建、发布和迭代您的应用，采用在网页开发中流行的预览部署工作流，并自动化您的开发流程。Expo 还能让您在完全不接触 Xcode 或 Android Studio 的情况下构建 React Native 应用，并且如果您想使用这些工具，Expo 也不会妨碍。

[Ignite](https://github.com/infinitered/ignite) 是一个带有多个 React Native 样板项目的启动工具命令行。最新版本 Ignite Maverick 使用 MobX-State-Tree 进行状态管理，采用 React Navigation 和其他常用库。它拥有屏幕、模型等生成器，并开箱支持 Expo。Ignite 还附带一个针对自定义设计、主题支持和测试优化的组件库。如果您正在寻找一个预配置的技术栈，Ignite 可能非常适合您。
