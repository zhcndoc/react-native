title: PerformanceResourceTiming
---

The global [`PerformanceResourceTiming`](https://developer.mozilla.org/en-US/docs/Web/API/PerformanceResourceTiming) class, defined in the Web specification.

:::warning[部分支持]

React Native 仅实现了以下 `PerformanceResourceTiming` 属性：

- `fetchStart`
- `requestStart`
- `connectStart`
- `connectEnd`
- `responseStart`
- `responseEnd`
- `responseStatus`
- `contentType`
- `encodedBodySize`
- `decodedBodySize`

:::
