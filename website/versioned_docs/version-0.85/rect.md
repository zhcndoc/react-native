title: Rect 对象类型
---

`Rect` 接受数值像素值来描述矩形区域延伸的距离。这些值会加到原始区域的尺寸上以将其扩展。

## 示例

```js
{
    bottom: 20,
    left: null,
    right: undefined,
    top: 50
}
```

## 键和值

### bottom

| 类型                        | 必需 |
| --------------------------- | -------- |
| number, `null`, `undefined` | 否       |

### left

| 类型                        | 必需 |
| --------------------------- | -------- |
| number, `null`, `undefined` | 否       |

### right

| 类型                        | 必需 |
| --------------------------- | -------- |
| number, `null`, `undefined` | 否       |

### top

| 类型                        | 必需 |
| --------------------------- | -------- |
| number, `null`, `undefined` | 否       |
