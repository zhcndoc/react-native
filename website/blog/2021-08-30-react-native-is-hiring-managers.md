我们最近分享了[React Native 的多平台愿景](https://reactnative.dev/blog/2021/08/26/many-platform-vision)，介绍了将 React 拓展到其他平台如何提升整个框架。过去几年中，我们通过与微软合作开发 Windows 和 macOS 版本的 React Native，以及与 Oculus 合作进行 VR 版本的 React Native，取得了显著进展。

正如我们[今年早些时候的计划](https://reactnative.dev/blog/2021/08/19/h2-2021)所述，我们正在加大对这些平台的关注并扩大团队规模，以实现我们的愿景。为了支持我们新的团队成员以及未来更多的员工，**我们正在招聘两位工程经理：一位负责支持 React Native 桌面端，另一位负责支持 React Native VR 端**。

我们寻找的是那些非常关心工程师成长与成功，并且对我们的愿景充满热情的经理。此前的 React 或 React Native 经验并非必需。此职位面向美国境内的所有人开放。如果这个机会让你感兴趣，想了解更多信息，请通过[Facebook 招聘页面](https://www.facebook.com/careers/v2/jobs/438516437547870)申请。期待收到你的消息！
