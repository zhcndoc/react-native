今天我们发布了 React Native 0.65 版本，带来了新版 Hermes、无障碍功能改进、依赖包升级等诸多更新。

## Hermes 0.8 有哪些新特性？

[Hermes](https://hermesengine.dev) 是 Facebook 为 React Native 优化的开源 JavaScript 虚拟机，本次升级到了 0.8.1 版本。本次发布的一些亮点功能包括：

- 引入了新的并发垃圾回收器 “Hades”，在 64 位设备上暂停时间最多缩短 30 倍。在 Facebook 内部，我们观察到部分 CPU 密集型任务性能提升了 20%-50%。可[在此了解 Hades](https://hermesengine.dev/docs/hades/)。
- [ECMAScript 国际化 API (ECMA-402，简称 `Intl`)](https://hermesengine.dev/docs/intl) 现已内置于 Android 版本的 Hermes 并默认启用，API 大小开销仅为 57-62K（相比之下，[JSC 达到 6MiB](https://github.com/react-native-community/jsc-android-buildscripts)）。因此 Hermes 用户不再需要地区语言相关的 polyfill。特别感谢 [@mganandraj](https://github.com/mganandraj) 及微软的合作伙伴们促成了这项实现！
- [iOS 版 Hermes](/blog/2021/03/12/version-0.64) 现已[支持 Apple M1 Mac 和 Mac Catalyst](https://github.com/facebook/hermes/pull/546)！
- 内存优化，包括小整数（SMI）和指针压缩，[使 JS 堆内存缩小了 30%](https://twitter.com/tmikov/status/1385629737121243140)。
- `Function.prototype.toString` 的改动，[修复了因错误的特征检测导致的性能下降](https://github.com/facebook/hermes/issues/471#issuecomment-820123463)，并[支持了源码注入的使用场景](https://github.com/facebook/hermes/issues/114)。

完整的 [Hermes 更新日志请见此处](https://github.com/facebook/hermes/releases)。

如果你尚未启用 Hermes，请[按这里的步骤](/docs/hermes#enabling-hermes)将你的应用切换到 Hermes，以享受以上新特性和性能提升！

## 无障碍修复和新增功能

去年，[Facebook 承诺加入 GAAD](https://reactnative.dev/blog/2021/05/20/GAAD-One-Year-Later) 提升 React Native 的无障碍体验。0.65 版本汇报了该承诺带来的成果以及其他无障碍改进！主要变化包括：

- 允许在 iOS 上指定高对比度的浅色和深色值，详情请参阅[文档](/docs/dynamiccolorios)。
- 在 Android 上新增了 [`getRecommendedTimeoutMillis`](/docs/accessibilityinfo#getrecommendedtimeoutmillis-android) API。该接口公开了用户在 Android 无障碍选项中设置的默认超时时间，方便需要更多时间查看或操作控件的用户。
- 修复了 TalkBack/VoiceOver 对组件状态（例如 `disabled` 和 `unselected`）的正确朗读。

你可以在这里关注或参与我们[待解决的无障碍问题](https://github.com/facebook/react-native/projects/15)！

## 依赖版本更新及注意事项

- `react-native-codegen` 版本 `0.0.7` 现在需要作为 `package.json` 中的 `devDependency`。
- JCenter 已经停止服务并转为只读。我们已移除 JCenter Maven 仓库，相关依赖改用 MavenCentral 和 Jitpack。
- OkHttp 升级到 v4.9.1，详情参见[升级到 OkHttp 4](https://square.github.io/okhttp/upgrading_to_okhttp_4/)。
- Flipper 升级到 0.93 版本，以支持 Xcode 12.5。详见 [Flipper 更新日志](https://github.com/facebook/flipper/blob/master/desktop/static/CHANGELOG.md)。
- 支持 Android Gradle Plugin 7。
- Apple Silicon 需要链接器的补丁，具体见 [@mikehardy 的说明](https://github.com/react-native-community/releases/issues/238#issuecomment-890367992)。
