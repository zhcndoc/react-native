去年，我们进行了用户访谈并发放了[一项调查问卷](https://www.surveymonkey.co.uk/r/DDZWQDJ)，以更多地了解人们在何时何地以及如何使用 React Native 文档。基于 24 次访谈和超过 3000 份调查响应的数据和指导意见，我们努力改进 React Native 的文档，今天很高兴与大家分享我们的进展：

- **[全新入门指南](https://reactnative.dev/docs/getting-started)** 我们推出了新的入门文档，向没有移动开发背景的人介绍了[什么是 Native 组件](https://reactnative.dev/docs/intro-react-native-components)。同时包含了一个 [React 复习/介绍](https://reactnative.dev/docs/intro-react)，帮助首次接触 React 的人快速上手！
- **[全新测试指南](https://reactnative.dev/docs/testing-overview)** 我们与 Vojtech Novak 合作，创建了一份新的插图测试指南，向应用开发者介绍不同种类的测试策略及其在 React Native 工作流程中的应用。
- **[全新安全指南](https://reactnative.dev/docs/security)** 我们与 Kadi Kraman 合作，制作了一份新的插图安全指南，解释了 React Native 环境中的安全基础，并提出了行业最佳解决方案。
- **更多插图** 新增了精美的插图，包括新的 [`Pressable`](https://reactnative.dev/docs/pressable) 组件及[React Native 组件介绍](https://reactnative.dev/docs/intro-react-native-components)文档。
- **https://reactnative.dev** 经过 5 年，我们终于迁移到了自己的域名！**reactnative.dev** 更易于从浏览器地址栏自动补全，也比之前的 **github.io** 地址更方便输入！
- **网站设计和架构改进** 我们更新了设计和站点架构，以更好地展示和分类更多指南，并提升 API 参考内容的可读性。特别感谢 [Bartosz Kaszubowski](https://github.com/Simek)，他的细致和协作使得许多改进得以快速实现！
- **核心组件和 API 文档更新** 我们发起了一项[文档更新行动](https://github.com/facebook/react-native-website/issues/1579)！借助参与者的帮助，我们及时为 0.62 版本全面更新了文档，并为所有文档添加了 Snack 示例：感谢 [Marta Dabrowka](https://twitter.com/martadabrowka)、[Abraham Nnaji](https://twitter.com/nnajiabraham)、[Ahmed Talaat El-Hager](https://twitter.com/ahmdtalat)、[Mohamed Abdel Nasser Abdou](https://twitter.com/mohamedsgap)、[Danilo Britto](https://twitter.com/danilobrinu)、[Mitul Savani](https://twitter.com/mitulsavani)、[Kaio Duarte](https://twitter.com/kaiodduarte)、[Pablo Espinosa](https://twitter.com/espipj)、[Jesse Katsumata](https://twitter.com/natural_clar)、[I Gede Agastya Darma Laksana](https://twitter.com/gedeagas)、[Sebastião Bruno Kiafuka Fernando](https://twitter.com/bruno_kiafuka)、[Miguel Bolivar](https://twitter.com/Darking360)、[Dani Akash](https://twitter.com/dani_akash_)、[Luiz Celso de Faria Alves](https://twitter.com/_eucelso) 和 [Bartosz Kaszubowski](https://twitter.com/simek) 的贡献。这些是迄今为止最佳且最新的 React Native 文档！
- **继续贡献 PR！** 我们能稳定地将每周待处理的 PR 保持在不到 10 个！感谢大家的贡献！

非常感谢所有参与访谈、填写调查和文档工作的朋友们！是你们的合作让这一切成为可能。

## 接下来是什么？

全球 COVID-19 大流行已影响了许多社区成员的工作。

我们正通过新增内容来应对，包括：

- 新的及改进的 Native 模块指南
- 针对首次接触 React Native 的用户的入门内容

### 你可以帮忙！

有很多方式可以帮助我们写出更好的文档！

1. 如果你发现拼写错误、指南中有问题，或者文档中有任何不妥之处，请点击“编辑”按钮并提交 PR。
2. [参与我们的调查](https://www.surveymonkey.co.uk/r/DDZWQDJ)—这有助于我们了解你如何使用 React Native 及其文档。
3. 为我们撰稿！我们正在制作教程栏目，以及针对离线应用、导航、无障碍访问、调试、动画、国际化和性能等主题的指南。如果你或者你认识的人非常适合这些主题，请[联系我](https://twitter.com/rachelnabors)！
